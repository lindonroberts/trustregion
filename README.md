# trustregion

This package is designed to have easy-to-use implementations of subproblem solvers for trust region and cubic regularization algorithms, for nonlinear optimization.

It is a newer version of the [trust-region](https://github.com/lindonroberts/trust-region/) Python package.

Several solvers are from [PRIMA](https://github.com/libprima/prima) under the BSD-3 licence.
